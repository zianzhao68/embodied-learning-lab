# 具身算法工程师成长主文档

> 这是本学习项目的唯一进度入口。每次学习后都要更新“当前状态、掌握度、学习记录、下一步”，以便在新会话中恢复上下文。

## 1. 学习者画像

- 背景：研究生，4 年工作经验，就职于中科创达，刚进入具身智能方向
- 已有能力：Python、PyTorch、深度学习；参加过机器人比赛，完成分割定位与运动控制抓取
- 待补能力：机器人学、3D 几何、控制、模仿学习、VLA、ROS2 工程体系
- 方向：以 VLA 操作为主线，以 3D 感知和运动控制为两翼
- 资源：2 张 A800；计划使用天工机器人，ROS2 接口，机器人尚未到位
- 时间：工作日每天 1～2 小时，周末 4～6 小时（不加班时）
- 学习特点：需要多次重复；采用主动回忆和第 1/3/7/14 天间隔复习

## 2. 总目标

在 9 个月内形成具身前沿算法工程师所需的完整能力链：

1. 能解释并实现坐标变换、运动学、视觉几何和基础控制。
2. 能构建和评测传统视觉抓取、模仿学习策略及 VLA 策略。
3. 能在仿真和真实机器人上完成数据采集、训练、部署、诊断与优化。
4. 形成至少 3 个可展示项目、3 篇技术报告和 1 个带对照实验的前沿复现/改进项目。

完整阶段规划见 [`docs/roadmap.md`](docs/roadmap.md)。

## 3. 固定学习与验收方式

### 工作日（标准 90 分钟）

- 15 分钟：不看资料，主动回忆旧知识
- 25 分钟：学习一个新知识点
- 40 分钟：推导、编码或实验
- 10 分钟：答题并记录结果

### 周末（4～6 小时）

- 1 小时复习
- 3 小时主项目
- 1 小时对照实验与排错
- 30～60 分钟整理文档、图表或演示

### 每个知识点的完成标准

- 能用自己的话解释原理
- 能看懂并推导核心公式
- 能根据图说明变量和坐标系
- 能独立完成至少一道计算题和一道工程题
- 能写出最小实现或完成实验
- 在第 1/3/7/14 天通过主动回忆复习

## 4. 网页课程项目

主站统一维护在 `site/`，采用 Astro 静态生成 + TypeScript + Content Collections + Markdown/MDX + KaTeX。旧版 Vite 原型保留在 `web/`，不再作为新增课程入口。

**课程标准的唯一来源**：[`docs/course-standard.md`](docs/course-standard.md)。开始任何新课程前必须先读取并逐项确认；用户提出的新标准必须先写入该文档和本主文档，不能只保留在聊天上下文中。课程模板位于 `site/templates/COURSE_TEMPLATE.mdx`。

架构与公网部署决策见 [`docs/architecture-and-deployment-decision.md`](docs/architecture-and-deployment-decision.md)。Astro 架构已实施；公开 GitHub 仓库与 Pages 自动部署工作流已配置，域名准备完成后可继续绑定自定义域名或接入 EdgeOne Makers。

本地启动：

```powershell
cd D:\vla\site
npm run dev
```

默认访问 `http://localhost:4321`，第一课为 `http://localhost:4321/courses/coordinate-frames/`。

新增课程约定：

1. 先读取 `docs/course-standard.md`。
2. 基于 `site/templates/COURSE_TEMPLATE.mdx` 在 `site/src/content/courses/` 新建课程。
3. 使用 frontmatter schema 注册标题、slug、阶段、时长、标签和发布状态。
4. 在 `site/src/data/quizzes.ts` 按课程 slug 注册测试题。
5. 图例放入 `site/public/assets/`；复杂交互后续使用按需加载的 Three.js island。
6. 执行 `npm run check`、`npm run build` 和 `npm audit`，并检查 390px 与 1440px 页面。
7. 测试成绩保存在当前设备 `localStorage`，正式学习结果仍同步回本主文档。
8. 新概念必须从熟悉例子渐进切入并逐一定义符号；必须区分真实分解分量与计算辅助方向并说明每一步目的；公式要解释构造来源，奇异性要包含触发机制、数值例子和不触发的反例；术语首次出现时给出常用中文、英文与别名。
9. 轨迹、旋转轴变化或分解重组依赖动态过程时，优先制作 Manim 动画；保留分镜和源代码，发布 H.264 MP4、海报和移动端原生播放控件，不自动播放；统一使用专业字体层级、网格布局、细坐标轴和克制箭头，并在正式渲染前检查关键帧完成视觉精修。
10. 表示切换必须强调物理动作未改变，并明确区分欧拉角的三次轴旋转、空间平移和四元数分量；四元数必须从同一个轴角例子，经纯四元数与夹心乘法逐步接入，不能只给半角公式。

## 8. 会话恢复协议

新会话开始时，让助手先读取本文件，然后：

1. 查看“当前状态”和最近一条“学习记录”。
2. 检查掌握度看板及到期复习项。
3. 从“下一步”继续，不重复已完成内容。
4. 每次学习结束后更新本文件，不只在聊天中汇报。
5. 如果计划发生改变，在学习记录中写明原因和设计偏差。
6. 制作新课前读取 `docs/course-standard.md`；任何新课程标准都必须写入该文件和本 README，禁止只依赖会话记忆。
