# IK、Jacobian 与奇异点动画分镜

## 核心视觉论点

IK 不是唯一反函数：同一目标可能对应多组关节角；Jacobian 描述每个关节的瞬时速度贡献，而奇异点是这些贡献方向变得线性相关，并非机械臂完全锁死。

## 场景

1. **同一目标，两种肘部**：肘上、肘下机械臂同时到达同一点，强调先判断工作空间再选解。
2. **Jacobian 的列**：分别只转动 q₁ 和 q₂，显示末端的两根切向速度箭头。
3. **奇异如何形成**：连续将 q₂ 收到 0，两根速度箭头逐渐共线；对比仍可运动的切向和丢失的径向。
4. **DLS 迭代**：从初值开始反复计算误差和 Jacobian，末端逐步靠近目标；阻尼抑制大步长。
5. **约束过滤**：解析/迭代候选依次经过可达性、关节限位、碰撞和连续性检查。
6. **总结海报**：多解、速度列、奇异方向三条结论。
