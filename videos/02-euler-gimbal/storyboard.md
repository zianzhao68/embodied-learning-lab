# 欧拉角顺序、内外旋与万向节锁动画分镜

## 核心视觉论点

欧拉角不是三个可随意交换的数字；顺序和参考轴决定过程，而万向节锁发生在中间旋转使首末两根有效轴共线时。

## 场景

1. **顺序不可交换**：同一向量分别执行 Rx→Ry 与 Ry→Rx，得到不同结果。
2. **内旋与外旋**：对比随物体移动的自身轴与固定世界轴，并展示内旋 ZYX = 外旋 XYZ 的等价叙事。
3. **正常 ZYX**：pitch 未到 ±90° 时，yaw、pitch、roll 三个方向独立。
4. **轴逐渐重合**：连续增加 pitch，显示 roll 轴转向并在 90° 与 yaw 轴反向共线。
5. **参数为什么不唯一**：显示多组 roll/yaw 具有相同差值；补充 roll 或 yaw 单独 90° 不会锁。
6. **诊断结论**：奇异的是参数化，不是机器人或 pitch 电机。
