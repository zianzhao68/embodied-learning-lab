# 深度图到点云动画分镜

## 核心视觉论点

深度图不是一张“立体照片”，而是每个像素的一条射线加一个深度；把所有有效格子沿各自射线放到指定位置，就得到仍保留像素对应关系的有组织点云。

## 场景

1. **3×3 深度表格**：逐格显示 z-depth 数值和主点，强调数组索引 D[v,u]。
2. **格子沿射线展开**：从光心发出九条射线，每个点停在自己的 Z；中心 2 m 点比周围 1 m 点更远。
3. **有组织与过滤**：0/NaN 位置保留叉号和 valid mask，再按行优先顺序过滤成 N×3。
4. **camera 到 base**：整片点云保持物理结构不变，只改变坐标表达，应用 T_base←camera。
5. **工程流水线**：depth + K → camera cloud + mask → RGB 对齐/过滤 → base cloud。
6. **总结海报**：像素、射线、深度、三维点四层关系。

## 渲染计划

- 16:9、1920×1080、30fps、H.264/yuv420p。
- 先做 480p/15fps smoke test和关键帧检查，确保九个点的顺序、无效 mask 和坐标变换文字清晰。
- 目标 22～30 秒；提供海报、原生控件和正文手算替代。
