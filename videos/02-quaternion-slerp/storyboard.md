# 四元数、双覆盖与 SLERP 动画分镜

## 核心视觉论点

单位四元数把轴角的半角编码到四维单位球面；q 与 −q 是同一姿态的两个坐标点，因此比较和插值必须先选择正确的符号分支。

## 场景

1. **轴角到半角**：物理旋转 α 与四元数圆截面上的 α/2 同步变化。
2. **单位约束**：四元数必须位于单位球面，网络输出需要归一化。
3. **双覆盖**：单位球面上的 q 与 −q 两个对跖点映射到同一个三维姿态。
4. **复合顺序**：先 q1 后 q2，总旋转为 q2⊗q1。
5. **SLERP 最短路径**：点积为负时先翻转 q1 的符号，避免绕远路。
6. **工程检查**：wxyz/xyzw、单位范数、符号连续性和主动/被动约定。
