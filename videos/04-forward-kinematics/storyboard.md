# 平面 2R 正运动学动画分镜

## 核心视觉论点

关节角描述相邻连杆的相对运动；上游角会带动整条下游链，因此第二连杆绝对方向是 q₁+q₂，末端位置是两根连杆向量的首尾相加。

## 场景

1. **上游关节带动下游**：固定 q₂，连续改变 q₁，肘部和末端一起运动。
2. **相对角不是世界角**：固定 q₁，只改变 q₂；标出 q₂ 相对第一连杆，第二连杆绝对方向为 q₁+q₂。
3. **向量首尾相加**：将两根连杆替换为两个向量，得到 x/y 三角函数公式和 30°/60° 数值结果。
4. **升级为变换链**：base→link1→link2→ee 逐段连接，强调相邻 frame 与矩阵顺序。
5. **标准 DH 四步**：按 Rz(θ)、Tz(d)、Tx(a)、Rx(α) 渐进出现，并警告 standard/modified 不可混用。
6. **总结海报**：相对角、向量和、变换链三条结论。
